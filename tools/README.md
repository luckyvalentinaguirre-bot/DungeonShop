# Herramientas de generación de arte (pixel art)

Scripts en Python (Pillow) que generan los PNG de pixel art del juego por código.
Permiten regenerar/ajustar el arte de forma reproducible.

- `gen_menu.py` — escena del menú principal (assets/ui/menu_*.png).
- `gen_pixelart.py` — pruebas de sprites sueltos.

Uso: `pip install Pillow` y `python3 tools/gen_menu.py`.
El arte final de un pixel artist puede sustituir estos PNG sin tocar el código.
